EQUIPMENT INVENTORY — TEST CASES
================================

Run each block in a new program session so entries from the previous block do not affect the result.

1. BASIC SCENARIO
-----------------
Input:
add; a1 ; Lamp ;3;12.50;2026-10-20
add;B2;Mouse;2;7.25;2027-01-01
list
find;a1
receive;A1;2
issue;b2;1
due;2026-12-31
total
quit

Expected output:
OK A1 3
OK B2 2
A1;Lamp;3;12.50;2026-10-20
B2;Mouse;2;7.25;2027-01-01
A1;Lamp;3;12.50;2026-10-20
OK A1 5
OK B2 1
A1;Lamp;5;12.50;2026-10-20
TOTAL 69.75

2. EMPTY REGISTRY
-----------------
Input:
list
due;2026-12-31
total
quit

Expected output:
EMPTY
EMPTY
TOTAL 0.00

An empty line or a line containing only spaces should not print anything.

7. COMMAND FORMAT AND UNKNOWN COMMAND
-------------------------------------
Command                      Expected result
receive;A1                   ERROR FORMAT
issue;A1;1;extra             ERROR FORMAT
find                         ERROR FORMAT
list;A1                      ERROR FORMAT
due                          ERROR FORMAT
total;extra                  ERROR FORMAT
delete;A1                    ERROR UNKNOWN

The quit command and EOF should end the program without extra output.
