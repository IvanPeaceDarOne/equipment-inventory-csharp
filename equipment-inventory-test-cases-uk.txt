КОНСОЛЬНИЙ РЕЄСТР ОБЛАДНАННЯ — СЦЕНАРІЇ ПЕРЕВІРКИ
===================================================

Запускай кожен блок у новому запуску програми, щоб записи з попереднього блоку не впливали на результат.

1. БАЗОВИЙ СЦЕНАРІЙ
-------------------
Ввід:
add; a1 ; Lamp ;3;12.50;2026-10-20
add;B2;Mouse;2;7.25;2027-01-01
list
find;a1
receive;A1;2
issue;b2;1
due;2026-12-31
total
quit

Очікуваний вивід:
OK A1 3
OK B2 2
A1;Lamp;3;12.50;2026-10-20
B2;Mouse;2;7.25;2027-01-01
A1;Lamp;3;12.50;2026-10-20
OK A1 5
OK B2 1
A1;Lamp;5;12.50;2026-10-20
TOTAL 69.75

2. ПОРОЖНІЙ РЕЄСТР
------------------
Ввід:
list
due;2026-12-31
total
quit

Очікуваний вивід:
EMPTY
EMPTY
TOTAL 0.00

Порожній рядок або рядок лише з пробілами не повинні нічого виводити.

7. ФОРМАТ КОМАНД І НЕВІДОМА КОМАНДА
------------------------------------
Команда                      Очікуваний результат
receive;A1                   ERROR FORMAT
issue;A1;1;extra             ERROR FORMAT
find                         ERROR FORMAT
list;A1                      ERROR FORMAT
due                          ERROR FORMAT
total;extra                  ERROR FORMAT
delete;A1                    ERROR UNKNOWN

Команда quit і EOF повинні завершувати програму без додаткового виводу.
