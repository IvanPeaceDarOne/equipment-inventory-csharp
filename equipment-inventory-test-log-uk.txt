Equipment Inventory — Test Log

Кожен сценарій запускався в новому сеансі програми.
Після кожної помилкової команди виконувався find або total,
щоб перевірити, що стан реєстру не змінився.

### Сценарій 1: Перевірка add, find і total

# Ввід:

add;a1;Lamp;3;12.50;2026-10-20
find;a1
total
quit

# Очікуваний результат:

OK A1 3
A1;Lamp;3;12.50;2026-10-20
TOTAL 37.50

# Фактичний результат:

OK A1 3
A1;Lamp;3;12.50;2026-10-20
TOTAL 37.50

# Сценарій 1: PASS

### Додаткова перевірка: EOF

Після коректної команди було надіслано EOF через Ctrl + Z, Enter у Windows-терміналі.
Програма завершилась без додаткового виводу та без помилки.

Статус: PASS

### Перевірка Debug і Release

Базовий сценарій був запущений у конфігураціях Debug і Release.
Вивід в обох конфігураціях однаковий.

Статус: PASS
